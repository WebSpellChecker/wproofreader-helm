# Security policy

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.
Use [GitHub private vulnerability reporting](https://github.com/WebSpellChecker/wproofreader-helm/security/advisories/new).
If private reporting is not available, email
[support@webspellchecker.net](mailto:support@webspellchecker.net).

Include the affected chart and application versions, the expected impact,
and steps to reproduce the problem.
Remove credentials, license data, and customer data from values, manifests, and logs.

Use a public [GitHub issue](https://github.com/WebSpellChecker/wproofreader-helm/issues)
for configuration errors and other reports that do not contain sensitive information.
